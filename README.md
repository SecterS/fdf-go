# FdF — каркасная 3D-модель карты высот на Go

Программа читает текстовую карту высот `.fdf` и показывает её в изометрии как сетку из линий.

## Установка и запуск

Нужны Go и зависимости из `go.mod`. Из папки проекта:

```sh
go run . maps/elem.fdf
```

Можно передать свой файл: `go run . путь/к/карте.fdf`.

## Управление

| Действие | Как сделать |
| --- | --- |
| Закрыть окно | Esc или крестик |
| Изменить размер | Потянуть край окна; карта подстроится сама |

## Формат карты

Каждая строка — ряд точек, числа — высоты. Во всех строках должно быть одинаковое число значений. Допускаются отрицательные высоты и необязательный цвет после запятой:

```text
0 1 0
-2 5,0xFF8800 1,0xff
0 1 0
```

Цвет хранится как `#RRGGBB`; например, `0xff` превращается в `#0000FF`. В обязательной части линии рисуются белым: чтение цвета требуется форматом, а цветная отрисовка относится к дополнительному заданию.

## Структура проекта

- `main.go` — аргумент командной строки, сообщения об ошибках и коды выхода.
- `parser.go` — чтение и проверка `.fdf`.
- `model.go` — точки, карта и соседи справа/снизу.
- `projection.go` — изометрия, масштаб и центрирование.
- `app.go` — окно Ebitengine и отрисовка.
- `fdf_test.go` — тесты парсера, модели и проекции.
- `GUIDE.md` — подробный разбор для защиты.

## Тесты и проверка

```sh
go test ./...
go vet ./...
gofmt -l *.go
```

Последняя команда ничего не выводит, если все Go-файлы отформатированы. Зависимость от графики есть только в `app.go`; тесты проверяют логику без открытия окна.
